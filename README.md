# Reelix Music

Your music, your way. A native Android app for streaming, discovering, and downloading your favorite tracks across multiple providers — featuring a stunning glassmorphic UI, real-time synced lyrics, and seamless playback.

| Platform | Link |
| :--- | :--- |

> **Note for Android users:** Since this APK is distributed outside the Play Store, you'll need to enable "Install from unknown sources" in your device settings before installing.

✨ **Features**

- 🌐 **Multi-Provider Support** — Stream millions of tracks across YouTube, Spotify, and Audiomack seamlessly in one app.
- 🎤 **Synced Lyrics** — Sing along with real-time, auto-scrolling lyrics powered by Musixmatch.
- 🎨 **Clean Glassmorphic UI** — A modern, translucent interface that adapts beautifully with a dynamic theme and dark-friendly design.
- ⚡ **Smooth Streaming** — Built natively with Kotlin and Jetpack Compose for high-performance playback and zero lag.
- 🔍 **Discover Weekly** — Find the sound you didn't know you needed with real-time, auto-generated recommendations based on user activity.
- ⬇️ **Offline Downloads** — Save your favorite tracks and playlists for offline listening, even without a connection.
- 🔐 **Account Support** — Sign in to sync your library, playlists, and preferences across sessions.

📲 **Installation (Android)**

1. Tap the **Download** link above.
2. Your browser will download the APK file.
3. Open the file. If prompted, allow installation from your browser or file manager: 
   * *Settings → Apps → Special access → Install unknown apps → [Your browser] → Allow*
4. Tap **Install** and you're done.

🔄 **Updates**

New versions are published as GitHub Releases. To update:

- Install it over your existing version — your data, playlists, and login are preserved.
